# wabuk-website
Official website of WaBuk

## WaBuk 서체 규칙

- 로고는 간판 원형을 담은 이미지로 사용한다. 흰색 WaBuk와 노란 곡선, 자간을 넓힌 BURGER가 한 단위다.
- 한글 제목과 소제목은 Noto Sans CJK KR Bold(700), 본문과 설명은 Regular(400)를 사용한다. 한글은 직립으로 조판한다.
- 영문 상단 메뉴와 페이지 분류명은 굵은 이탤릭 대문자로 표시한다. 메뉴 자간은 0.025em, 분류명은 0.12em이다.
- 공통 서체는 css/style.css에서 관리한다. assets/fonts의 웹폰트에는 현재 본문 글자와 기본 영문이 들어 있다. 추가한 글자가 파일에 없으면 기기의 한글 고딕 서체로 표시된다.
